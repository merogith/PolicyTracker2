How the documentation score works

From a response to a country

A documented response earns 1 point. Sourced Responsibility, Timeframe and Output / milestone each add 1 point: 1–4 points, shown as 25–100. Context has no claim score.

Topic: average response score. Domain: average of its fixed home topics. Country: average of all 64 topics. A completely searched topic without a response is 0; incomplete work remains unknown.

Read colors and changes

Arrows show documentation-score change between matched new editions. Refresh means a source or method update. These are documentation measures, not climate performance.

Claims are unique organized propositions; repeated quotes are not extra claims. The regional benchmark includes only the same source and topic profile.
